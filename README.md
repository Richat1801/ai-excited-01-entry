A goldfish leaps out of a teacup on a night windowsill, and its splash bursts into stars that arc up to a big cratered full moon — the sky fits in a teacup. The scene is drawn entirely by `main.ts`: a procedural SDF render (sky, moon, cup, leaping fish, star arc, and a 5×7 bitmap caption for the judge) with its own PNG encoder, Node 22 standard library only, no assets and no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
