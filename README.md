Entry for [ai-excited-01 on make.fun](https://make.fun/bounty/ai-excited-01) — one image made to get the AI judge excited.

A goldfish leaps out of a teacup on a night windowsill, and its splash bursts into stars that arc up to a big cratered full moon: a whole sky hiding in a teacup. The scene is drawn fully procedurally by `main.ts` (Node 22, standard library only) — night-sky gradient, starfield, cratered moon, splash-arc of droplets turning into stars, the leaping goldfish, and the teacup on its saucer — with a legible line to the judge in a 5×7 bitmap font: **"THE SKY FITS IN A TEACUP!"**

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png` (1024×1024 PNG, deterministic — two runs produce identical bytes).
